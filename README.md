# Quai Francilien des Jeunes Bridgeurs

Landing page and club site for the Quai Francilien des Jeunes Bridgeurs (QFJB), a bridge club for players under 40 in the Paris region.

## Local development

Prerequisites:
- Node.js
- npm or bun

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the local app
- `npm run build` — create a production build
- `npm run preview` — preview the built app
- `npm run lint` — run ESLint

## Project goals

- Recruit new members and curious beginners
- Showcase club events and community life
- Present a modern, dynamic brand for bridge
